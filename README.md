# Roundhouse Workout Timer: public pages

GitHub Pages site for the Roundhouse Roku app: a landing page and the
privacy policy / terms of use (the URLs given in the Roku store listing).
Plain static HTML, no build step. The app itself lives in a separate
private repo.

- `index.html`: landing page
- `privacy/index.html`: privacy policy, plus terms of use and the health &
  safety disclaimer at `privacy/#terms`
